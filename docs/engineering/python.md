# Python

## Purpose

Python is used for backend services, scripting, data tooling, and CLI
development.

## Manager

`uv` is the primary Python project and package manager. It replaces
`pip`, `pip-tools`, `virtualenv`, `pyenv`, and `poetry` for most use
cases.

System Python (currently `python@3.14` via Homebrew on macOS) is used
only to bootstrap `uv` itself. Project Python is selected per-project by
`uv`.

## Conventions

- **Project layout**: `pyproject.toml` + `uv` lockfile (`uv.lock`).
- **Tooling**: installable via `uv tool install <name>` (Ruff, mypy, etc.)
  or per-project as a dev dependency.
- **Linting**: Ruff (replaces flake8, isort, pyupgrade, etc.).
- **Formatting**: Ruff format (replaces Black for new projects; Black is
  acceptable in existing repos).
- **Type checking**: `mypy` or `pyright`, configured per-project.
- **Testing**: `pytest`.
- **ASGI dev server**: `uvicorn`.

## Global CLI tools (uv tool)

Capture with:

```bash
uv tool list
```

Typical entries:

- `ruff`
- `mypy` or `pyright`
- `pytest`
- `uvicorn`

## Project virtual environments

`.venv/` directories are NEVER migrated. They are regenerated by
`uv sync` (or `uv venv && uv pip install ...`) on the new machine from
the committed `pyproject.toml` + `uv.lock`.

## Windows path

`uv` works on native Windows and inside WSL2. The preferred location is
**WSL2** so that Python tooling shares the same filesystem as Go, Docker
volumes, and Linux-oriented CLIs.

If WSL2 is unavailable:

```powershell
winget install --id Python.Python.3.13
# or install uv directly:
winget install --id astral-sh.uv
```
