# Documentação em Português (Brasil)

Este diretório é reservado para documentação traduzida / localizada para
pt-BR. Está intencionalmente vazio por enquanto.

Política:

- Manter o conteúdo em inglês como fonte da verdade em
  [`../en`](../en) (na prática, todo o conteúdo atualmente está na raiz de
  `docs/`).
- Ao adicionar conteúdo em pt-BR, espelhar a estrutura do diretório
  inglês.
- Não duplicar decisões; referenciar o original em inglês quando
  aplicável.
